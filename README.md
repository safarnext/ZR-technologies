# ZR Technologies — Premium landing page

This is a separate static HTML/CSS/JS build. It does not modify the existing Cloudflare Pages site.

## Preview locally
Open `index.html` in a modern browser with an internet connection (animation libraries and fonts load from CDNs).

## Deploy as a separate Cloudflare Pages project
Upload the contents of this folder to a new Pages project. No build command is needed; the output directory is the project root.

## Before launch
- Replace `hello@zr-technologies.com` in `index.html` with your confirmed business email.
- Review all service wording and CTAs.
- Test the contact action after replacing the email.
- Libraries used: GSAP + ScrollTrigger, Lenis, Three.js, Anime.js, AOS. AOS is used for basic section reveals; GSAP handles bespoke scroll choreography.
- Reduced-motion users get static/non-animated content.
